# Keepsake publishing operations

## Source of truth

`keepsake-builder.html` **in this repo** is the only supported keepsake template and generator. The old hand-edited template is retired, and so is the copy of the builder that briefly lived in the `keepsakes` repo — it predated the consent/page-code/downloads upgrade and pointed its CTA at tinyurl. Client pages and examples must be generated by this builder so privacy metadata, media downloads, accessibility behavior, and brand styling stay consistent.

Delivered keepsake pages are published in the separate `keepsakes` repo (served at `/keepsakes/<page-code>/`), keeping client work out of this marketing repo. Generated pages link the Story Room directly and carry the studio's GA4 tag.

## Required delivery checklist

Every delivered keepsake must contain:

- an opaque page code and filename;
- `noindex, nofollow` metadata;
- approved title, dedication, story, artwork, alt text, and lyrics;
- a valid unlisted YouTube link;
- an MP3 with in-page playback and download;
- a printable lyric-sheet PDF;
- an explicit client publishing approval check.

## Privacy boundary

`noindex` prevents ordinary search indexing; it does not make a page private. A public Git repository also preserves names and stories in git history.

Before publishing real client work:

1. Use first names unless the client explicitly approves more.
2. Review the story for addresses, contact details, medical details, and other sensitive information.
3. Keep real client keepsakes out of the public marketing repository.
4. Publish them through a separate service with access control when privacy is promised.
5. Do not use a client-side JavaScript password screen as security.

Until separate hosting is configured, the builder can create and preview a finished file, but publishing that file to this public repository requires deliberate client approval.

## Drafts

Draft files are downloaded locally and can include the complete story, artwork, MP3, and PDF. Store them as client-confidential files and delete them when no longer needed.
